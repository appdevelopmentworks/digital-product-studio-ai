## 2. LP 固有の差分(Brand-specific design directives)

[design-system-template.md §1.4](../../../docs/templates/design-system-template.md) のフォーマットで記述。

### 2.1 ヒーロー幅広レイアウト

- **目的**: LP 即読性を最大化(コーポレートサイトより装飾を抑える)
- **適用範囲**: `/` のヒーローセクションのみ
- **必須 / 推奨**: MUST
- **検証方法**: モバイル / デスクトップで「最初の 3 秒で価値が伝わる」をユーザーテスト
- **具体指示**:
  - max-width: 1280px(aileap_v2 default 同じ)だが padding を SP で 16px・PC で 24px(aileap_v2 PC 48px より狭い)
  - ヒーローテキスト max-width: 720px(中央寄せ・読みやすさ優先)
  - CTA ボタン: 大サイズ(高さ 56px / aileap_v2 中サイズ 44px より大きい)で目立たせる

### 2.2 セクション間のリズム強化

- **目的**: LP のスクロール誘導を最適化
- **適用範囲**: 全セクション
- **必須 / 推奨**: MUST
- **具体指示**:
  - セクション間 vertical margin: PC `space-24`(96px)/ SP `space-16`(64px)
  - aileap_v2 §4.2 では `space-16-24` だが、LP では更に余裕を持たせる
  - アンカーリンク用の scroll-margin-top: 80px(固定ヘッダー考慮)

### 2.3 申込みフォームの強調

- **目的**: CV 率最大化
- **適用範囲**: 申込みフォームセクション
- **必須 / 推奨**: MUST
- **具体指示**:
  - フォーム背景色: `bg.muted`(#F5F5F8)で本文セクションと差別化
  - 送信ボタン: フルワイドの大ボタン(高さ 56px)
  - エラーメッセージ: `state.error` + 太字 + アイコン併用
  - 送信中: ボタン disabled + スピナー(連打防止)

### 2.4 MeetingAI プロダクトロゴの配置

- **目的**: AILEAP ブランド配下のプロダクトであることを明示
- **適用範囲**: ヘッダー / フッター / 申込みフォーム
- **必須 / 推奨**: MUST
- **具体指示**:
  - ヘッダー左: AILEAP コーポレートロゴ + 縦区切り + MeetingAI プロダクトロゴ
  - フッター: AILEAP コーポレートロゴのみ(プロダクト紹介はサイト本文で十分)
  - 申込みフォーム上部: MeetingAI プロダクトロゴ(申込みコンテキストの明示)

### 2.5 LP 特有の意図的「装飾削減」

- **目的**: LP 即読性最大化(aileap_v2 はもっと装飾的)
- **適用範囲**: 全 LP
- **必須 / 推奨**: MUST
- **具体指示**:
  - パララックス禁止
  - 自動再生動画禁止
  - 装飾的なグラデーション背景は最小限(ヒーローのみ可)
  - aileap_v2 のような「メンバーアバター」「タイムライン」等の装飾要素は本 LP では不要

## 5. アニメーション最小限ポリシー

- スクロール時のフェードイン(opacity 0 → 1)のみ許容
- パララックス禁止
- ヒーローでの動画自動再生禁止
- `prefers-reduced-motion: reduce` 時はすべての transition を 0.01ms に(継承)
